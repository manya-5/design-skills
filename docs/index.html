design-handoff

Turns screens into a spec engineers can build from, with every state written down and open questions listed instead of guessed.

Skill files The spec template

What it checks that mockups usually leave out:

  • Empty, loading, error and success states
  • Very long text and missing images
  • Hover, focus, pressed and disabled for every control
  • 1 item and 1,000 items
  • Slow networks, retries, leaving mid-way
  • Keyboard order and screen reader labels
  • Text contrast below 4.5:1
  • For AI: what happens before, during, when it's wrong, and undo

Install

git clone https://github.com/manya-5/design-skills.git
cp -r design-skills/skills/* ~/.claude/skills/

In the Claude apps, you can also zip a skill's folder and upload it from Settings.
